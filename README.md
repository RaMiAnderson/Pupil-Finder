# School Management Platform

This school management platform is built using **Node.js, Express, EJS, and MongoDB**, designed to centralize and simplify academic operations.

It allows the administration to manage students, teachers, and staff through a role-based access system. The platform handles key features such as student records, grade tracking, tuition fee management, class schedules, attendance monitoring, and school announcements.

Each user (student, teacher, and admin) has a dedicated account with specific roles and permissions. The interface is dynamically rendered using **EJS**, while **MongoDB** is used for scalable and flexible data storage.
